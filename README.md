This repository implements steps for the following procedures:
1. Data cleaning
2. Parallel analysis and exploratory factor analysis
3. Graded Response Modeling: covers item selection, local dependence testing (Q3), model and Item-level fit statistics
4. Invariance Testing by Sex
5. Invariance Testing by Age
6. Invariance Testing by Clinical Status
7. Cut-off Score, Internal Consistency, and External Anchor
